** CSV rules
1. Each entry is separated by a delimeter (,)
2. Line terminates with line terminator "\n"
   1. Terminator is optional at the last line
3. OPTIONAL File can start with a header, but in no way it can be determined with the format
4. OPTIONAL Each record (line) should have the same number of fields
5. A field containing the a (,), (") or (\n) character should be enclosed in double quotes (")
   - Any field may be enclosed in double quotes
6. If a field is enclosed in double quotes, then a double quote embedded in the field must be represented by a sequence of two double quotes
** EBNF notation of a CSV file
- <CSV-file> ::= {<CSV-line>} <CSV-last-line>
- <CSV-line> ::= [<CSV-entry>] {,<CSV-entry>} \n
- <CSV-last-line> ::= [<CSV-entry>] {,<CSV-entry>} [\n]
- <CSV-entry> ::= <String> | " <String> & ( \n | "" | , ) "
** Parsing plan - only recording of relational positions, no strcpy-s
- Read the buffer
- By looping over the file: parse all lines
  - Sequentially search for "\n", if there is a combination of ",\"" - scan and skip all \n inside until "\","
  - Terminate on "\0"
  - Number of lines is height of the file
- By looping over the lines positions: parse all entries
  - Sequentially search for ",", if the next thing is a ","" - scan and skip all "," and "\"" until ",\""
  - Terminae on length of the line
  - Number of saved entries is the width of the file
